# Portabla Media

**Communication and the web — with AI as a co-worker, not a gimmick.**

Portabla Media works with digital strategy, web development and communication. We believe in sharing what we build — that's why we publish the methods and models we use in our daily work.

## Our public work

### [Dialogue Synthesis / Dialogsyntes](https://github.com/PortablaMedia/dialogue-synthesis)

A lightweight, platform-independent model for preserving decisions, rationale and reusable lessons from qualified AI dialogues — so that knowledge and stringency survive across sessions, tools and people.

Freely available in Swedish and English under CC BY 4.0. README with both languages: [`dialogue-synthesis`](https://github.com/PortablaMedia/dialogue-synthesis)
